## 2. สิ่งที่แต่ละคนต้องรู้

### Member 2

### Member 3

- คุณเล่าภาพรวมระบบ แหล่งข้อมูล และฐานข้อมูล CRM (สไลด์ 6–8)
- ภาพรวมใช้ชื่อ 6 คอลัมน์ของอาจารย์ (บทที่ 1): Sources / Ingestion and transport / Storage / Query and processing / Transformation / Analysis and output
- 4 ประเภทข้อมูล: CRM = structured, แชต JSON = semi-structured + ข้อความ = unstructured, ไฟล์แท็บเล็ต = semi-structured, ปฏิทิน = external
- Incremental = ดึงเฉพาะแถวที่ UpdatedAt ใหม่กว่ารอบที่แล้ว (ลบ 5 นาทีเผื่อ transaction ที่ commit ช้า) และส่งรายการ primary key มาตรวจแถวที่ถูกลบ
- OLTP: 13 ตาราง = master 8 + transaction 5, 3NF; ข้อยกเว้นเล็กๆ อยู่ในสไลด์สำรอง A5

### Member 4

- ชื่อ zone ตามอาจารย์ (บทที่ 4): landing → raw → trusted → refined (+ quarantine, sandbox); ในโค้ดเราเรียก raw = Bronze, trusted = Silver

- กฎคุณภาพที่ตรวจทุกคืน 37 ข้อ (ใน rules.yml เขียนไว้ 39 ข้อ อีก 2 ข้อ S02, C04 ยังเป็นแผน ยังไม่ได้เขียนตัวตรวจ)
